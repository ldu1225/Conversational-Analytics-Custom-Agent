# 📊 BigQuery Logs Analyst Agent (ADK)

이 프로젝트는 구글 빅쿼리(BigQuery) 감사 로그 테이블들로부터 사용자의 자연어 질문을 해독하여 **동적 SQL을 자동으로 생성 및 실행하고, 대화의 맥락을 완벽히 이해하는 멀티턴 세션 메모리와 실시간 차트 시각화 컴파일러를 탑재한 최첨단 Vertex AI Reasoning Engine 에이전트** 패키지입니다.

어떠한 스크립트 코딩 수정 없이 **단 1개의 설정 파일 수정만으로 타사 또는 타 빅쿼리 데이터셋에 100% 동적으로 대응할 수 있는 데이터 독립적 범용 패키지**로 제공됩니다.

---

## 🌟 핵심 탑재 기능

1. **지능형 NL2SQL 데이터 분석:** 자연어 지시를 파싱하여 여러 테이블을 자동으로 `UNION ALL` 또는 `JOIN`하는 정교한 ANSI SQL을 생성 및 실행합니다.
2. **Stateful 멀티턴 대화 지원:** `GCP ConversationReference`를 동적으로 바인딩하여, "위 내용으로 그래프 추이 보여줘"와 같이 대상을 지칭하지 않는 연속적인 세션 질문 맥락을 완벽히 해독합니다.
3. **어댑티브 비즈니스 리포터:** LLM이 데이터 조회 결과를 역해독하여 실제 수치에 기반한 정밀 비즈니스 발견점 단락("주요 인사이트")을 컨설팅 수준으로 상세 기술합니다.
4. **인메모리 지능형 차트 컴파일러:** 파일 시스템 접근 권한이나 클라우드 스토리지 업로드 제약 없이, 런타임 데이터 세만틱을 자동 해독하여 **최상급 꺾은선 그래프(시계열 추이) 및 막대 그래프(비교 분석)를 base64 PNG 이미지로 실시간 렌더링**해 냅니다.
5. **스트리밍 중복 방지 기술:** 분할 전송되는 클라우드 채널에서 중복 출력을 원천 격리하여, 고객 화면에 단 하나의 깨끗한 보고서 레이아웃만 렌더링되도록 통제합니다.

## ⚙️ 1단계: 환경 구축 및 사전 요구사항

고객님의 구글 클라우드(GCP) 환경에서 배포하기 위해 다음 준비물이 필요합니다.

### 1. 필수 CLI 도구 설치
로컬 컴퓨터(또는 배포 서버)에 `gcloud` 및 ADK 패키지를 설치합니다:
```bash
# 1. Google Cloud SDK 설치 확인
gcloud --version

# 2. Python 3.10 이상 설치 확인
python3 --version

# 3. Google ADK 및 필수 의존성 라이브러리 통합 설치 (필수)
pip install -r requirements.txt
```

### 2. 대상 빅쿼리 로그 테이블 준비
감사 로그(Audit Log) 또는 분석 대상이 될 BigQuery 테이블들을 활성화해 주십시오.

---

## 🔧 2단계: 커스터마이징 및 스왑 설정 (가장 쉬움!)

고객님의 테이블 정보와 프로젝트 정보를 매핑하기 위해 단 하나의 파일만 수정하면 됩니다.

### 📍 `ca_api_agent/config.py` 편집
프로젝트 루트의 `ca_api_agent/config.py` 파일을 엽니다.
상단에 정의된 4가지 설정값을 고객님의 프로젝트 및 테이블 구조에 맞게 텍스트 치환(스왑)해 줍니다:

```python
# ca_api_agent/config.py

# 1. 고객님의 GCP 프로젝트 ID와 배포될 리전을 적어주세요.
PROJECT_ID = "고객님의_GCP_프로젝트_ID"
LOCATION = "us-central1"  # Vertex AI 리전 지정 (global 연동)

# 2. 에이전트가 지능적으로 스캔하고 UNION/JOIN할 빅쿼리 테이블들을 적어주세요.
# (원하는 개수만큼 여러 개를 배열 형태로 자유롭게 등록할 수 있습니다!)
TABLES = [
    {"dataset_id": "감사로그_데이터셋_명칭", "table_id": "감사로그_테이블_명칭_1"},
    {"dataset_id": "감사로그_데이터셋_명칭", "table_id": "감사로그_테이블_명칭_2"},
    {"dataset_id": "감사로그_데이터셋_명칭", "table_id": "감사로그_테이블_명칭_3"}
]

# 3. 대화창 화면 상단에 표기될 에이전트의 이름을 지정해 주세요.
AGENT_DISPLAY_NAME = "Enterprise BQ Logs Analyst Agent"
```
*💡 **참고:** 테이블의 컬럼 구조를 일일이 가르쳐 줄 필요가 없습니다. 에이전트가 BQ 메타데이터 스키마를 실시간으로 자동 디스커버리하여 SQL을 조립해 냅니다.*

## 🚀 3단계: 원클릭 배포 (Two Steps!)

설정값 스왑이 끝나면 다음 단 두 단계의 명령어로 구글 클라우드 Vertex AI Reasoning Engine 가동을 완벽하게 시작할 수 있습니다.

### Step 1. Google Cloud 인증
터미널에서 고객님의 배포 권한을 가진 계정으로 인증해 줍니다:
```bash
gcloud auth login
gcloud auth application-default login
```

### Step 2. Reasoning Engine 배포 스크립트 실행
루트 폴더에서 배포 자동화 스크립트를 실행합니다:
```bash
python3 deploy.py
```

콘솔 로그에 다음과 같이 ✅ 표시와 함께 신규 에이전트 리소스 ID 주소가 출력되면 **대성공**입니다!
```text
Deployment completed successfully!
✅ Created agent engine: projects/고객님프로젝트/locations/us-central1/reasoningEngines/4197269640558149632
```

## 💬 4단계: 에이전트 활용 시뮬레이션

배포된 에이전트는 웹 대시보드 또는 API 스트림을 통해 즉시 비즈니스 쿼리 서비스를 제공합니다.

### 대화 질문 예시
1. **자연어 조회 (Turn 1):**
   > *"최근 3달간 가장 많은 사용을 한사람 탑3를 보여줘"*
   * **에이전트 반응:** BQ 데이터를 분석하여 탑3 유저 이메일과 총 로그 빈도수를 깔끔한 표로 요약하고, 관리자 계정의 점유율(95%) 및 보안상 분리 제안을 담은 **"주요 인사이트 보고서"**를 품격있게 작성합니다.

2. **Stateful 멀티턴 그래프 요청 (Turn 2):**
   > *"그래프로 사용량추이도 보여줘"*
   * **에이전트 반응:** 1차 질문의 탑3 유저를 정확하게 기억하여, 이들을 **일별 사용량 변동폭을 나타내는 시계열 꺾은선 그래프(Matplotlib Line Chart)를 base64 PNG 이미지 형태로 대화창 내부에 다이렉트 렌더링**해 냅니다!

## 🛠️ 트러블슈팅 (Troubleshooting)

### 1. 라이브러리 설치 중 `protobuf` 관련 경고(Warning)가 발생합니다.
* **현상:** `pip install -r requirements.txt` 실행 중 `protobuf` 의존성 충돌 경고가 나타날 수 있습니다.
* **원인:** 로컬 파이썬 환경의 기존 레거시 구글 클라우드 패키지 중 일부가 구버전의 protobuf를 요구하지만, 본 에이전트에 탑재된 최신 GenAI SDK 패키지는 최신 버전의 protobuf(`4.25.x` 이상)를 끌어오기 때문에 pip가 출력하는 종속성 경고입니다.
* **해결:** 이는 **런타임 작동 및 배포에 전혀 영향을 미치지 않는 단순 Warning(경고)**이므로 안전하게 무시하고 진행하셔도 무방합니다.
